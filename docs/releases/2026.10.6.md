# 2026.10.6

_Released 2026-10-14 · [compare 2026.10.3…2026.10.6](https://github.com/perosb/qvantum_custom_component/compare/2026.10.3...2026.10.6) · [all releases](https://github.com/perosb/qvantum_custom_component/tree/main/docs/releases)_

The adaptive heating curve now better accounts for heating time, room temperatures and sunshine, and shows how well rooms track their target, how much evidence supports each adjustment, and where its estimates are less certain. New home-heating estimates show how quickly rooms cool and how much the sun helps, while curve learning and its readiness checks work more reliably; removing the integration returns the pump to its own automatic curve. Fixes also keep room-temperature and other readings consistent, retry interrupted solar measurements sooner, and preserve the latest heating and hot-water efficiency readings after a restart.

## Clearer release highlights

Release highlights can be added to a release before it is published, so the announcement includes the same overview as the release notes. Re-running the process keeps the existing highlights rather than creating a different version.

_Related: [#338](https://github.com/perosb/qvantum_custom_component/pull/338)_

## More stable device entities

Entity identities remain stable even if Home Assistant changes how it represents device information. This helps prevent existing entities from being recreated under new names.

_Related: [#340](https://github.com/perosb/qvantum_custom_component/pull/340)_

## More reliable external room temperature readings

External room temperature readings are now recorded for cloud and Modbus setups, and a new reading can fall back to another available room temperature while its history builds. This helps the adaptive curve and other measurements use the room temperature the heat pump is actually following.

_Related: [#344](https://github.com/perosb/qvantum_custom_component/pull/344), [#348](https://github.com/perosb/qvantum_custom_component/pull/348), [#352](https://github.com/perosb/qvantum_custom_component/pull/352)_

## Clearer adaptive-curve readiness and room tracking

The curve’s readiness check now focuses on heating periods and accounts for room compensation, making it more representative of how the pump operates. New room-error information shows how closely indoor temperatures follow the target, and room compensation is only applied to the reading it was learned from.

_Related: [#342](https://github.com/perosb/qvantum_custom_component/pull/342), [#343](https://github.com/perosb/qvantum_custom_component/pull/343), [#350](https://github.com/perosb/qvantum_custom_component/pull/350), [#354](https://github.com/perosb/qvantum_custom_component/pull/354)_

## More dependable curve trims

Curve trims now use heating periods, and the first trim can be calculated sooner once there is enough evidence. Per-point evidence and information about extrapolated points help explain which adjustments are supported by observations and which extend beyond them.

_Related: [#353](https://github.com/perosb/qvantum_custom_component/pull/353), [#355](https://github.com/perosb/qvantum_custom_component/pull/355), [#356](https://github.com/perosb/qvantum_custom_component/pull/356), [#357](https://github.com/perosb/qvantum_custom_component/pull/357)_

## Safer curve cleanup and fuller diagnostics

When the integration is removed, an active adaptive curve is returned to the pump’s own automatic curve when it is safe to do so. Support information now includes more of the curve’s readiness, room-compensation, trim, and coverage details.

_Related: [#347](https://github.com/perosb/qvantum_custom_component/pull/347), [#359](https://github.com/perosb/qvantum_custom_component/pull/359)_

## Improved solar learning

The adaptive curve can now estimate solar heating from daily energy patterns, including sunny periods when the pump is not actively heating. If a calibration attempt cannot retrieve the needed data, it retries sooner; completed or permanently unavailable attempts keep their normal schedule.

_Related: [#360](https://github.com/perosb/qvantum_custom_component/pull/360), [#361](https://github.com/perosb/qvantum_custom_component/pull/361)_

## New insights into home heat storage

New building measurements estimate how quickly rooms cool when heating pauses and how much heat the home can store. They appear only when there is enough data to support an estimate.

_Related: [#358](https://github.com/perosb/qvantum_custom_component/pull/358)_

## COP readings stay available

Heating and hot-water COP readings are restored after a Home Assistant restart and remain visible until a new measurement is available. The sensors also show when each reading was last calculated and how old it is.

_Related: [#362](https://github.com/perosb/qvantum_custom_component/pull/362)_

_Internal changes (refactor / tests / CI / docs), not described in detail: #336, #337, #341, #345, #346, #351._

> [!IMPORTANT]
> Setup is **Cloud HTTP** or **local Modbus**.
> Local Modbus is read-only until writing is enabled.
> SmartControl stay cloud-only.


> [!WARNING]
> **Modbus mode**
> Enabling Modbus writing means you accept full responsibility for values written to the pump.
> Incorrect or out-of-range values may void the warranty and/or affect lifecycle and performance.


> [!WARNING]
> **Cloud mode**
> Elevate access assigns "Remote Service" (service tech) rights to your user. Cloud HTTP only.
> Cloud mode uses the same internal API as the app. Use at your own risk ;)
