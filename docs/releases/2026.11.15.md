# 2026.11.15

_Released 2026-11-28 · [compare 2026.11.14…2026.11.15](https://github.com/perosb/qvantum_custom_component/compare/2026.11.14...2026.11.15) · [all releases](https://github.com/perosb/qvantum_custom_component/tree/main/docs/releases)_

The heating curve now adjusts for lasting differences between the indoor temperature and its target, shows that adjustment, and lets it ease back so it won’t keep the home too cold; this feature is on by default and can be switched off. Room temperature now comes from the selected reading, with a backup used only when the selected reading is missing and the backup is detected and plausible; the external-temperature picker also hides this integration’s own readings and rejects them if selected. A new count shows how many days the curve operated beyond its measured range, counting each day only once, and the new setting now has an explanation in all eleven supported languages.

## Gradual correction for lingering room-temperature differences

The heating curve can now adjust for a room-temperature difference that persists over time. The adjustment can also ease back toward zero when the difference subsides, rather than leaving a lasting correction in place.

_Related: [#587](https://github.com/perosb/qvantum_custom_component/pull/587), [#588](https://github.com/perosb/qvantum_custom_component/pull/588)_

## See the room-error contribution on the curve card

The curve card now shows the room-error contribution. While it is waiting to build up, it shows the 24-hour average room-temperature difference instead of appearing inactive.

_Related: [#590](https://github.com/perosb/qvantum_custom_component/pull/590)_

## Use the configured indoor temperature reading

The heat pump now uses the configured indoor temperature reading for its room value. It falls back to the backup reading only when the configured reading is unavailable and the backup reading is suitable.

_Related: [#591](https://github.com/perosb/qvantum_custom_component/pull/591)_

## Prevent self-referencing room-temperature feeds

When choosing an external room-temperature source, you can no longer select a temperature provided by this integration. The integration also rejects such a source if it is supplied another way.

_Related: [#592](https://github.com/perosb/qvantum_custom_component/pull/592)_

## Track days the heating curve reaches beyond its measured range

The exported curve statistics now include the number of days the curve operated outside its measured range, counting each day once. Existing counts still show which end of the range was exceeded.

_Related: [#594](https://github.com/perosb/qvantum_custom_component/pull/594)_

_Internal changes (refactor / tests / CI / docs), not described in detail: #589._

> [!IMPORTANT]
> Setup is **Cloud HTTP** or **local Modbus**.
> Local Modbus is read-only until writing is enabled.
> SmartControl stay cloud-only.


> [!WARNING]
> **Modbus mode**
> Enabling Modbus writing means you accept full responsibility for values written to the pump.
> Incorrect or out-of-range values may void the warranty and/or affect lifecycle and performance.


> [!WARNING]
> **Cloud mode**
> Elevate access assigns "Remote Service" (service tech) rights to your user. Cloud HTTP only.
> Cloud mode uses the same internal API as the app. Use at your own risk ;)
