# 2026.11.8

_Released 2026-11-18 · [compare 2026.11.7…2026.11.8](https://github.com/perosb/qvantum_custom_component/compare/2026.11.7...2026.11.8) · [all releases](https://github.com/perosb/qvantum_custom_component/tree/main/docs/releases)_

The integration now records how long each heating-curve adjustment has been at its limit, reports how close it is, and restores this information reliably. Once the curve has been ready for 24 hours, it can ask whether you want to activate it, but it won’t activate it for you. The curve display now shows the adjustment actually in effect and its supporting measurements, while estimates of how the home responds to heating account for adjustments changing over time; this measured drift is for information only. Reports now include the forecast air temperature, and Learn more points to an overview of how the curve works.

## Track how long heating adjustments have reached their limit

The integration now records when an adjustment reaches its limit and includes how long it has been there in diagnostic information. This information is preserved across restarts, helping distinguish a newly capped adjustment from one that has been capped for a while.

_Related: [#509](https://github.com/perosb/qvantum_custom_component/pull/509), [#510](https://github.com/perosb/qvantum_custom_component/pull/510), [#511](https://github.com/perosb/qvantum_custom_component/pull/511)_

## Make heating-curve adjustments clearer

The curve card now shows the adjustment currently in effect instead of adding together adjustments for different outdoor temperatures. It also shows per-temperature adjustments and their supporting evidence in the details.

_Related: [#513](https://github.com/perosb/qvantum_custom_component/pull/513), [#514](https://github.com/perosb/qvantum_custom_component/pull/514)_

## Improve room-gain diagnostic accuracy

Room-gain diagnostics now account for adjustments changing over time, reducing misleading results when readings from before and after an adjustment are combined. This measurement is for diagnostics and does not change how the curve is applied.

_Related: [#515](https://github.com/perosb/qvantum_custom_component/pull/515)_

## Include forecast temperature in diagnostic information

Diagnostic information now includes the forecast air temperature alongside the curve’s outdoor-temperature contribution, making it easier to compare like with like.

_Related: [#516](https://github.com/perosb/qvantum_custom_component/pull/516)_

## Get a prompt when the curve is ready to activate

When the curve has met its readiness requirements for 24 hours, the integration can ask whether you want to activate it. You can activate it or decline, and the prompt will not repeat unless readiness is lost and later achieved again.

_Related: [#517](https://github.com/perosb/qvantum_custom_component/pull/517)_

## Find a clearer introduction to the adaptive curve

The curve’s Learn more link now leads to an introduction explaining how it learns, how readiness works, and what safety measures apply.

_Related: [#518](https://github.com/perosb/qvantum_custom_component/pull/518)_

> [!IMPORTANT]
> Setup is **Cloud HTTP** or **local Modbus**.
> Local Modbus is read-only until writing is enabled.
> SmartControl stay cloud-only.


> [!WARNING]
> **Modbus mode**
> Enabling Modbus writing means you accept full responsibility for values written to the pump.
> Incorrect or out-of-range values may void the warranty and/or affect lifecycle and performance.


> [!WARNING]
> **Cloud mode**
> Elevate access assigns "Remote Service" (service tech) rights to your user. Cloud HTTP only.
> Cloud mode uses the same internal API as the app. Use at your own risk ;)
