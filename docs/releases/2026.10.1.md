# 2026.10.1

_Released 2026-10-05 · [compare 2026.9.16…2026.10.1](https://github.com/perosb/qvantum_custom_component/compare/2026.9.16...2026.10.1) · [all releases](https://github.com/perosb/qvantum_custom_component/tree/main/docs/releases)_

This release adds an adaptive heating curve that learns from your heat pump and local weather, with solar and forecast-based adjustments, optional manual activation, safety limits, and a new dashboard card; it can also keep an external room-temperature reading updated automatically. Fixes make availability and controls clearer when writing is disabled, improve recovery from polling and saved-data problems, and make requests and setting changes safer and more reliable. It also corrects temperature ranges and fractional room-compensation values, removes unsupported Eco and Smart hot-water choices, and improves sensor history and statistics.

## More reliable updates and recovery

The integration now handles failed updates, interrupted requests and saved timer data more safely. It also responds to cloud service throttling and reports connection problems more clearly.

_Related: [#275](https://github.com/perosb/qvantum_custom_component/pull/275), [#277](https://github.com/perosb/qvantum_custom_component/pull/277)_

## Controls match your access

You can still view temperatures and equipment status when your account or setup does not allow changes. Controls that cannot work are hidden, and attempts to change settings without permission are refused.

_Related: [#274](https://github.com/perosb/qvantum_custom_component/pull/274), [#278](https://github.com/perosb/qvantum_custom_component/pull/278)_

## Safer settings and clearer hot-water options

Invalid or out-of-range settings are blocked, and direct pump connections now support the documented room-temperature adjustment values. Hot-water modes are consistent across connection types, controls appear only where supported, and selected readings can be used for long-term statistics.

_Related: [#276](https://github.com/perosb/qvantum_custom_component/pull/276), [#280](https://github.com/perosb/qvantum_custom_component/pull/280), [#296](https://github.com/perosb/qvantum_custom_component/pull/296), [#297](https://github.com/perosb/qvantum_custom_component/pull/297), [#300](https://github.com/perosb/qvantum_custom_component/pull/300)_

## Adaptive heating curve

A new optional heating curve uses weather forecasts, sunlight and pump data to calculate adjustments and learn how your home responds. You can preview it before enabling control; when active, it checks changes and returns to the normal curve if a safety check fails.

_Related: [#282](https://github.com/perosb/qvantum_custom_component/pull/282), [#283](https://github.com/perosb/qvantum_custom_component/pull/283), [#285](https://github.com/perosb/qvantum_custom_component/pull/285), [#286](https://github.com/perosb/qvantum_custom_component/pull/286), [#287](https://github.com/perosb/qvantum_custom_component/pull/287), [#290](https://github.com/perosb/qvantum_custom_component/pull/290), [#291](https://github.com/perosb/qvantum_custom_component/pull/291), [#293](https://github.com/perosb/qvantum_custom_component/pull/293)_

## See and understand the adaptive curve

Curve points now appear in the same order as the pump’s curve. Diagnostics include curve details, and a new dashboard card lets you view the baseline, calculated curve, active points and adjustments.

_Related: [#289](https://github.com/perosb/qvantum_custom_component/pull/289), [#294](https://github.com/perosb/qvantum_custom_component/pull/294), [#295](https://github.com/perosb/qvantum_custom_component/pull/295)_

## Keep an external room temperature sensor up to date

You can select a Home Assistant temperature sensor to regularly send its smoothed reading to the pump, even when the room temperature stays steady. The integration also records feed status and write errors to help with troubleshooting.

_Related: [#299](https://github.com/perosb/qvantum_custom_component/pull/299)_

_Internal changes (refactor / tests / CI / docs), not described in detail: #279, #281, #288, #292, #298._

> [!IMPORTANT]
> Setup is **Cloud HTTP** or **local Modbus**.
> Local Modbus is read-only until writing is enabled.
> SmartControl stay cloud-only.


> [!WARNING]
> **Modbus mode**
> Enabling Modbus writing means you accept full responsibility for values written to the pump.
> Incorrect or out-of-range values may void the warranty and/or affect lifecycle and performance.


> [!WARNING]
> **Cloud mode**
> Elevate access assigns "Remote Service" (service tech) rights to your user. Cloud HTTP only.
> Cloud mode uses the same internal API as the app. Use at your own risk ;)
