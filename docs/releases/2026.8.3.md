# 2026.8.3

_Released 2026-08-24 · [compare 2026.8.1…2026.8.3](https://github.com/perosb/qvantum_custom_component/compare/2026.8.1...2026.8.3) · [all releases](https://github.com/perosb/qvantum_custom_component/tree/main/docs/releases)_

The integration now includes Finnish, Czech, and Danish translations, with clearer Czech and Danish wording. Home Assistant can now restart even when the heat pump’s online service is unavailable.

> [!IMPORTANT]
> Setup is **Cloud HTTP** or **local Modbus**.
> Local Modbus is read-only until writing is enabled.
> SmartControl stay cloud-only.


> [!WARNING]
> **Modbus mode**
> Enabling Modbus writing means you accept full responsibility for values written to the pump.
> Incorrect or out-of-range values may void the warranty and/or affect lifecycle and performance.


> [!WARNING]
> **Cloud mode**
> Elevate access assigns "Remote Service" (service tech) rights to your user. Cloud HTTP only.
> Cloud mode uses the same internal API as the app. Use at your own risk ;)

## More language options

The integration is now available in Czech, Danish and Finnish, with clearer Czech and Danish translations.
