# 2026.11.6

_Released 2026-11-16 · [compare 2026.11.5…2026.11.6](https://github.com/perosb/qvantum_custom_component/compare/2026.11.5...2026.11.6) · [all releases](https://github.com/perosb/qvantum_custom_component/tree/main/docs/releases)_

This update makes energy-efficiency figures use the same time period for all measurements, helping prevent misleading results when data starts at different times. The indoor sensor setting is now included consistently in exported data so readings from different sources can be compared; unrecognized settings remain blank.

## More reliable SCOP measurements

SCOP counters are now compared over the same time period, helping prevent misleading results when their recorded histories begin at different times.

_Related: [#503](https://github.com/perosb/qvantum_custom_component/pull/503)_

## Improved sensor-mode reporting

The indoor sensor mode reported by the cloud is now shown consistently with the value reported by the heat pump’s local connection. Unrecognized sensor-mode names remain unavailable rather than being shown as an incorrect value.

_Related: [#504](https://github.com/perosb/qvantum_custom_component/pull/504)_

> [!IMPORTANT]
> Setup is **Cloud HTTP** or **local Modbus**.
> Local Modbus is read-only until writing is enabled.
> SmartControl stay cloud-only.


> [!WARNING]
> **Modbus mode**
> Enabling Modbus writing means you accept full responsibility for values written to the pump.
> Incorrect or out-of-range values may void the warranty and/or affect lifecycle and performance.


> [!WARNING]
> **Cloud mode**
> Elevate access assigns "Remote Service" (service tech) rights to your user. Cloud HTTP only.
> Cloud mode uses the same internal API as the app. Use at your own risk ;)
