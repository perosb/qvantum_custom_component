# 2026.11.5

_Released 2026-11-16 · [compare 2026.11.3…2026.11.5](https://github.com/perosb/qvantum_custom_component/compare/2026.11.3...2026.11.5) · [all releases](https://github.com/perosb/qvantum_custom_component/tree/main/docs/releases)_

Highlights: The integration now uses the heat pump’s own total power reading when available. Restored history is handled more reliably, keeping long-term efficiency and performance measures available. Implausible energy jumps are ignored so they don’t distort heating-load estimates.

## More reliable long-term performance statistics

Efficiency and operating statistics now continue to work when stored history is restored or merged, instead of being blanked by a reset in the recorded totals.

_Related: [#498](https://github.com/perosb/qvantum_custom_component/pull/498)_

## Protection against implausible heating readings

Unusually large jumps in reported heating energy no longer distort derived heating-load estimates. The previous reading is held while the pump’s updates catch up.

_Related: [#500](https://github.com/perosb/qvantum_custom_component/pull/500)_

## More accurate whole-unit power readings

On supported firmware, the integration uses the pump’s own total-power reading for a more accurate estimate of the unit’s electricity use. Older firmware and readings of zero continue to use the existing estimate.

_Related: [#501](https://github.com/perosb/qvantum_custom_component/pull/501)_

_Internal changes (refactor / tests / CI / docs), not described in detail: #502._

> [!IMPORTANT]
> Setup is **Cloud HTTP** or **local Modbus**.
> Local Modbus is read-only until writing is enabled.
> SmartControl stay cloud-only.


> [!WARNING]
> **Modbus mode**
> Enabling Modbus writing means you accept full responsibility for values written to the pump.
> Incorrect or out-of-range values may void the warranty and/or affect lifecycle and performance.


> [!WARNING]
> **Cloud mode**
> Elevate access assigns "Remote Service" (service tech) rights to your user. Cloud HTTP only.
> Cloud mode uses the same internal API as the app. Use at your own risk ;)
