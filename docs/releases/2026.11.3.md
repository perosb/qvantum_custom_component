# 2026.11.3

_Released 2026-11-13 · [compare 2026.11.2…2026.11.3](https://github.com/perosb/qvantum_custom_component/compare/2026.11.2...2026.11.3) · [all releases](https://github.com/perosb/qvantum_custom_component/tree/main/docs/releases)_

The heating-curve display now shows how much recent load data supports an adjustment, which curve points are estimates, how much evidence supports adjusted points, and how close the indoor temperature is to the adjustment limit. The summary adds 90-day performance figures alongside 30-day figures and counts of why automatic curve control was reverted; the card footer layout is also fixed. The documentation and tests now correctly describe which indoor temperature reading is used when a mode sensor is unavailable; the system’s behavior is unchanged.

## More insight into adaptive heating adjustments

The adjustment sensor and card now show how much load data has been collected, helping explain when a zero adjustment reflects a balanced home versus a window that is still filling. The card also shows when curve points are extrapolated, how much evidence supports trims, and the indoor margin before a limit takes effect.

_Related: [#492](https://github.com/perosb/qvantum_custom_component/pull/492), [#493](https://github.com/perosb/qvantum_custom_component/pull/493)_

## Compare 30-day and 90-day SCOP

The summary export now includes 90-day SCOP alongside the 30-day figure, making it easier to compare recent performance with a longer seasonal view.

_Related: [#494](https://github.com/perosb/qvantum_custom_component/pull/494)_

## See why adaptive control was reverted

The summary export now breaks down curve reverts by reason, helping distinguish issues such as disabled control, failed writes, or rejected settings.

_Related: [#495](https://github.com/perosb/qvantum_custom_component/pull/495)_

_Internal changes (refactor / tests / CI / docs), not described in detail: #496, #497._

> [!IMPORTANT]
> Setup is **Cloud HTTP** or **local Modbus**.
> Local Modbus is read-only until writing is enabled.
> SmartControl stay cloud-only.


> [!WARNING]
> **Modbus mode**
> Enabling Modbus writing means you accept full responsibility for values written to the pump.
> Incorrect or out-of-range values may void the warranty and/or affect lifecycle and performance.


> [!WARNING]
> **Cloud mode**
> Elevate access assigns "Remote Service" (service tech) rights to your user. Cloud HTTP only.
> Cloud mode uses the same internal API as the app. Use at your own risk ;)
