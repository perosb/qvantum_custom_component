# 2026.10.9

_Released 2026-10-19 · [compare 2026.10.8…2026.10.9](https://github.com/perosb/qvantum_custom_component/compare/2026.10.8...2026.10.9) · [all releases](https://github.com/perosb/qvantum_custom_component/tree/main/docs/releases)_

Weather forecasts and sunlight estimates now remain available through brief fetch failures when the previous data is still current. Heating and hot-water efficiency readings now assign auxiliary heating correctly, measure hot-water performance for each tank-heating cycle using an identified tank volume, and retain useful readings after restarts. Curve information now shows when points are extrapolated or limited, and low baseline points are raised to the pump’s minimum. Heating and hot-water priority settings now use valid 30-minute intervals, the unsupported cooling setting has been removed, compressor power averages work, and release downloads show the correct version.

## More reliable weather-based calculations

A failed weather refresh no longer removes forecast data that is still current, helping keep related calculations available. The integration also indicates when it is reusing a saved forecast.

_Related: [#377](https://github.com/perosb/qvantum_custom_component/pull/377)_

## More accurate heating and hot-water COP

Electrical use from the auxiliary heater is now attributed to hot water when it heats the tank, rather than distorting the space-heating COP. Hot-water COP is updated using the energy actually delivered, including a limit for element-only heating.

_Related: [#378](https://github.com/perosb/qvantum_custom_component/pull/378)_

## Clearer and more reliable heating curves

Curve points now show when they are estimated beyond the outdoor temperatures observed so far or limited by the pump, with an optional overview of curve coverage. Baseline points below the pump’s minimum supply temperature are raised to that minimum so they are not stuck below the usable range.

_Related: [#384](https://github.com/perosb/qvantum_custom_component/pull/384), [#385](https://github.com/perosb/qvantum_custom_component/pull/385)_

## Priority-window controls

Modbus users can view and set the heating, cooling and hot-water priority windows in minutes, in 30-minute steps. Heating and hot-water windows cannot be set below 30 minutes in the controls, while cooling can be set to zero.

_Related: [#386](https://github.com/perosb/qvantum_custom_component/pull/386), [#389](https://github.com/perosb/qvantum_custom_component/pull/389), [#391](https://github.com/perosb/qvantum_custom_component/pull/391)_

## Compressor power readings

A compressor power sensor is now available, allowing its readings to be recorded and used to calculate an average while the compressor is running.

_Related: [#387](https://github.com/perosb/qvantum_custom_component/pull/387)_

## Hot-water standing loss survives restarts

The hot-water standing-loss estimate is saved and restored when Home Assistant restarts, avoiding the need to wait for a new measurement window before the sensor becomes available again.

_Related: [#388](https://github.com/perosb/qvantum_custom_component/pull/388)_

> [!WARNING]

> Enabling Modbus writing means you accept full responsibility for values written to the pump.
> Incorrect or out-of-range values may void the warranty and/or affect lifecycle and performance.


> [!WARNING]
> **Cloud mode**
> Elevate access assigns "Remote Service" (service tech) rights to your user. Cloud HTTP only.
