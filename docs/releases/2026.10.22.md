# 2026.10.22

_Released 2026-10-31 · [compare 2026.10.20…2026.10.22](https://github.com/perosb/qvantum_custom_component/compare/2026.10.20...2026.10.22) · [all releases](https://github.com/perosb/qvantum_custom_component/tree/main/docs/releases)_

Hot-water draw power now reflects actual use more clearly, and GP2 pump speed readings are corrected. QG heat pumps can show readings for each compressor unit, and known alarms now have clearer names. The documentation has also been expanded to explain heat-pump models, measurements, energy figures, and compressor readings.

## More accurate pump readings

The GP2 pump speed now displays as a realistic percentage instead of values that could exceed 100%. On supported QG models, you can also see separate diagnostic readings for each compressor unit and its brine pump.

_Related: [#452](https://github.com/perosb/qvantum_custom_component/pull/452), [#460](https://github.com/perosb/qvantum_custom_component/pull/460)_

## Clearer hot-water power readings

Hot-water draw power now reflects the estimated power at the time of use, rather than changes in the energy counter. The energy reading remains available separately.

_Related: [#455](https://github.com/perosb/qvantum_custom_component/pull/455)_

## More informative alarm codes

Known alarm codes now include a plain-language description to help explain what the code means. Unknown codes remain without a description rather than being given a guessed meaning.

_Related: [#461](https://github.com/perosb/qvantum_custom_component/pull/461)_

> [!IMPORTANT]
> Setup is **Cloud HTTP** or **local Modbus**.
> Local Modbus is read-only until writing is enabled.
> SmartControl stay cloud-only.


> [!WARNING]
> **Modbus mode**
> Enabling Modbus writing means you accept full responsibility for values written to the pump.
> Incorrect or out-of-range values may void the warranty and/or affect lifecycle and performance.


> [!WARNING]
> **Cloud mode**
> Elevate access assigns "Remote Service" (service tech) rights to your user. Cloud HTTP only.
> Cloud mode uses the same internal API as the app. Use at your own risk ;)
