# 2026.11.7

_Released 2026-11-16 · [compare 2026.11.6…2026.11.7](https://github.com/perosb/qvantum_custom_component/compare/2026.11.6...2026.11.7) · [all releases](https://github.com/perosb/qvantum_custom_component/tree/main/docs/releases)_

Firmware information now displays consistently and no longer reverts to an older version after a restart. Efficiency and heating estimates now show how many days of data they use, and diagnostics include more detail to help explain when an estimate is missing. Heating-power data is now available for both connection types, allowing heating and heat-loss estimates to use it.

## Clearer firmware and fit coverage

Firmware information is presented consistently, and efficiency summaries show how many days of data support the seasonal and building estimates. This makes it easier to tell how much data those figures are based on.

_Related: [#505](https://github.com/perosb/qvantum_custom_component/pull/505)_

## Firmware updates stay visible

After setup checks for a firmware update, the device page now keeps showing the checked version instead of reverting to an older cached version after a restart.

_Related: [#506](https://github.com/perosb/qvantum_custom_component/pull/506)_

## More context for missing estimates

Diagnostics now include details about the data used for building estimates, making it easier to understand why an estimate may be unavailable.

_Related: [#507](https://github.com/perosb/qvantum_custom_component/pull/507)_

## Building estimates work with cloud data

Cloud-connected pumps now record the heating power data needed for building efficiency estimates. This allows those estimates to be calculated from cloud data as well as from local connections.

_Related: [#508](https://github.com/perosb/qvantum_custom_component/pull/508)_

> [!IMPORTANT]
> Setup is **Cloud HTTP** or **local Modbus**.
> Local Modbus is read-only until writing is enabled.
> SmartControl stay cloud-only.


> [!WARNING]
> **Modbus mode**
> Enabling Modbus writing means you accept full responsibility for values written to the pump.
> Incorrect or out-of-range values may void the warranty and/or affect lifecycle and performance.


> [!WARNING]
> **Cloud mode**
> Elevate access assigns "Remote Service" (service tech) rights to your user. Cloud HTTP only.
> Cloud mode uses the same internal API as the app. Use at your own risk ;)
